# 訂單權限與狀態管理

WordPress／WooCommerce 外掛，提供 LC 與享物後台需要的訂單狀態、帳號權限、發票狀態與確認狀態管理。

## 安裝與設定

1. 在 WordPress 後台上傳 Release 提供的 ZIP 並啟用。
2. 開啟「訂單權限管理」。
3. 套用「LC 後台」或「享物後台」範本。
4. 指定出貨／業務、會計及老闆帳號。
5. 檢查每個角色可切換的狀態後儲存。

## 權限行為

- 出貨／業務與會計帳號無法刪除訂單或訂單備註。
- 兩類帳號只能切換面板中勾選的狀態；批次操作也使用相同限制。
- 老闆帳號不限制狀態。
- 會計與老闆可設定獨立發票狀態，並可在訂單列表勾選「確認狀態」。

## 發布

推送 `v*` 標籤後，GitHub Actions 會建立 Release 並上傳可安裝 ZIP。
